# Celebal Technologies Summer Internship 2026

## Week 3 Assignment

### Objective

The objective of this assignment is to perform SQL analysis on the Superstore dataset using Subqueries, Common Table Expressions (CTEs), and Window Functions. The dataset is imported into MySQL and organized into separate tables for customers, products, and orders.

---

## Dataset

- Sample Superstore Dataset
- Imported into `superstore_raw`
- Data separated into:
  - customers
  - products
  - orders

## Tasks Performed

- Imported the Superstore dataset into MySQL.
- Created separate tables for customers, products, and orders.
- Inserted data using SELECT DISTINCT.
- Performed analysis using Subqueries.
- Used CTEs to calculate customer sales.
- Ranked customers using Window Functions.
- Generated customer sales insights through SQL queries.

---

## Mini Project

The following business questions were answered:

- Top 5 customers
- Bottom 5 customers
- Customers with only one order
- Customers with above-average sales
- Highest order value for each customer
