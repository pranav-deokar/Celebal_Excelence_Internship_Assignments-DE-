# Week 5 Assignment – Apache Spark DataFrame Operations

This repository contains the solutions for **Week 5** of the **Celebal Technologies Internship**. The assignment focuses on Apache Spark fundamentals, DataFrame operations, data cleaning, transformations, aggregations, and Spark's processing architecture.

## Topics Covered

- Apache Spark vs MapReduce
- In-Memory Computing
- Data Cleaning
- Handling Duplicate Records
- Handling Null Values
- DataFrame Filtering
- GroupBy and Aggregations
- Data Type Casting
- Column Renaming
- Spark Transformations
- Shuffle Operations
- ETL Pipeline using Spark DataFrames

## Assignment Questions

The assignment includes solutions for the following:

1. Limitations of MapReduce and advantages of Spark
2. In-Memory Computing in Spark
3. Removing duplicate rows
4. Filtering and grouping DataFrames
5. Handling null values using `.na.drop()` and `.na.fill()`
6. Counting records using `groupBy()`
7. DataFrame immutability
8. Multiple condition filtering
9. Importance of handling null values before aggregations
10. Timestamp conversion and column renaming
11. Shuffle operation in Spark
12. Removing invalid records
13. Multiple aggregations using `.agg()`
14. Risks of using `inferSchema=True`
15. Building a simple ETL pipeline
