# E-Commerce Order Analytics System

## Internship Assignment — Assignment 8

### Overview

The **E-Commerce Order Analytics System** is a Python and SQL-based data analytics project that simulates a real-world e-commerce data processing workflow.

The project generates and processes **orders, order items, products, and customer data**, including intentional data-quality issues such as missing values, incorrect date formats, invalid emails, inconsistent product names, and product returns.

### Key Components

- **Data Generation:** Creates realistic interconnected e-commerce datasets.
- **Data Cleaning & Validation:** Identifies and handles data-quality issues and checks referential integrity.
- **SQLite Database:** Stores the cleaned datasets in a relational structure.
- **SQL Analysis:** Performs revenue analysis, customer segmentation, return analysis, ranking, running totals, cohort analysis, YoY comparison, and other advanced SQL operations.
- **Python + SQL Integration:** Generates business reports containing orders, revenue, customers, top products, and period comparisons.
- **Edge Case Testing:** Tests invalid references, discounts, quantities, and future dates.
- **Product Pair Analysis:** Identifies products frequently purchased together.

### Significance

The assignment demonstrates a complete **data processing and analytics workflow**:

**Raw Data → Cleaning → Validation → Database → SQL Analysis → Business Reporting**

It provides practical experience with **Python, SQL, SQLite, data cleaning, relational databases, window functions, CTEs, and business analytics**.
